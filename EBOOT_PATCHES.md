# Pre-Patched 60 FPS EBOOTs & Update PKGs

Ready-made game executables with the FPS patch **baked in** — no Artemis, no PS3MAPI, no manual hex editing. Made and shared by **Nascar1243**.

- 📺 Tutorial video: [60FPS patched EBOOTs are finally here, here is how to install them!](https://www.youtube.com/watch?v=4RWYxVHZj_E)
- 📦 Download (MEGA): <https://mega.nz/folder/EQtmTaSb#ozzCXUhc0gTt40KMGMhxcg>

> Requires a PS3 with Custom Firmware (or HEN). The MEGA folder contains one directory per game; **binaries are not mirrored in this repo** — only this index is.

---

## How to install

**Patched `EBOOT.BIN`:**
1. Back up the original: `/dev_hdd0/game/<TITLEID>/USRDIR/EBOOT.BIN` (or your game folder in `GAMES/`)
2. Copy the patched `EBOOT.BIN` to `hdd0/GAMES/(Game of choice)/USRDIR`, overwriting the original

**Update PKGs (`2PATCH-….pkg`):**
1. Copy the `.pkg` files to `/dev_hdd0/packages`
2. Install them from **Package Manager → Install Package Files → PS3 System Storage**

**Config-file games:** F.E.A.R. 2 uses an `autoexec.cfg` and Syndicate uses a `USER.CFG` dropped into the game's folder instead of a patched executable.

> **Some game folders contain a `Notes.txt`** — read it first; it documents known issues or a different install location for that specific game.
